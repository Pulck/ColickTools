## 附录：问卷使用指南（供插件维护者参考）

### 数据收集方式
- 每次大版本更新后定向邀请填写
- 样本量目标：n ≥ 5 时观察趋势，n ≥ 20 时归纳

### 分析框架

| 问题 | 信号 | 设计决策 |
|------|------|---------|
| Q1 自动匹配频率低 | 触发条件不够精确 | 修改 description 关键词 |
| Q2 漏触发 | AI 未将 skill 内化为行为 | 在 CLAUDE.md 追加行为锚点 |
| 2.1 某条勾选率高 | 该要求约束力不足或不可执行 | 强化具体触发条件，或降级/删除 |
| 2.2 "上下文压缩"勾选率高 | 记忆型要求不可行 | 增加"当前动作披露"替代"完整追溯" |
| 2.2 "子代理缺少上下文"勾选率高 | 上下文隔离成本被低估 | 调整准入条件或增加上下文传递机制 |
| Q3 冲突频繁 | 优先级不明确 | 增加冲突裁决规则 |
| 3.1 "调用工具后未说明"勾选率高 | 披露要求未生效 | 绑定到具体动作（如 Read 后必须报告） |
| 4.1 集中指向同一条要求 | 该要求应删除 | 参考具体场景决定 |
| 4.4 反馈明确 | 假设不成立 | 修改 skill |
